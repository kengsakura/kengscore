# KengScore · ระบบบันทึกคะแนนการส่งงาน

เว็บแอปสำหรับครูบันทึกการส่งงานและคะแนนของนักเรียน แยกตาม **รายวิชา · ห้อง · ภาคเรียน · ปีการศึกษา**
ใช้ได้ทั้งคอมพิวเตอร์และมือถือ หักคะแนนส่งช้าให้อัตโนมัติ และสรุปคะแนนรวมส่งออกเป็น Excel ได้

- **Frontend:** React 19 + Vite + Tailwind CSS (SPA ไฟล์ static โหลดเร็ว ไม่มี server ต้องรอ cold start)
- **Database / Auth:** Supabase (PostgreSQL) region **Singapore** ใกล้ไทยที่สุด (~30 ms)
- **Hosting:** Vercel (ฟรี, CDN ทั่วโลก)
- ความปลอดภัย: ครูแต่ละคนเห็นเฉพาะข้อมูลของตัวเอง (Row Level Security ในฐานข้อมูล)

## ความสามารถ

| หน้า | ทำอะไรได้ |
| --- | --- |
| **หน้าหลัก** | สรุปจำนวนนักเรียน/ห้อง/วิชา/งาน · ปุ่มลัดไปกรอกคะแนนแต่ละห้อง · งานล่าสุด |
| **กรอกคะแนน** | เลือกวิชา → ห้อง → งาน แล้วกรอกเร็ว ๆ: พิมพ์คะแนน + Enter ไปคนถัดไป, ปุ่ม **เต็ม** แตะครั้งเดียว, ปุ่ม “เต็มทุกคนที่ยังไม่ส่ง”, ค้นหาด้วยเลขที่ แล้ว Enter, ตัวกรอง ยังไม่ส่ง/ส่งแล้ว/ส่งช้า, บันทึกอัตโนมัติทันที |
| **วันที่ส่ง** | ค่าเริ่มต้น = วันนี้ · นักเรียนมาส่งทีหลังก็บันทึกเป็นวันนั้น ระบบหักคะแนนตามจำนวนวันที่ช้าให้เอง · แก้วันที่ส่งรายคนได้ · กำหนดส่งปรับแยกรายห้องได้ (ห้องเรียนคนละวัน) · ยกเว้นการหักคะแนนรายคนได้ (เช่น ลาป่วย) |
| **คะแนนรวม** | ตารางคะแนนทุกงาน แยกกลุ่มตามประเภท · รวม/ร้อยละ/แปลงเป็นคะแนนเก็บ (เช่น /70) · จำนวนงานค้าง · มุมมอง “ตามประเภท” · เฉพาะคนค้างงาน · ส่งออก CSV (เปิดใน Excel ภาษาไทยได้) · พิมพ์ A4 แนวนอน |
| **นักเรียน** | id, ชั้น, ห้อง, เลขที่, เลขประจำตัว, คำนำหน้า, ชื่อ, นามสกุล (แยกตามภาคเรียน) · เพิ่มทีละคน / **วางจาก Excel ทั้งห้อง** / นำเข้า CSV · คัดลอกจากภาคเรียนอื่นพร้อม “เลื่อนชั้น” · ย้ายห้อง/ลบหลายคน · จัดการห้อง |
| **รายวิชาและห้อง** | เพิ่มรายวิชา (รหัส ชื่อ สี คะแนนเก็บเต็ม) และเลือกห้องที่สอนวิชานั้น |
| **ตั้งค่า** | ชื่อผู้สอน/โรงเรียน · ภาคเรียน-ปีการศึกษาที่กำลังทำงาน · ประเภทงาน (สมุด ใบงาน สอบเก็บคะแนน ชิ้นงาน …) · นโยบายหักคะแนนส่งช้า · เปิด/ปิดให้นักเรียนดูคะแนน · เปลี่ยนรหัสผ่าน |
| **นักเรียนดูคะแนน** (`/s`) | นักเรียนกรอก **รหัสดูคะแนน 8 ตัว** หรือสแกน QR แล้วเห็นคะแนนของตัวเองทุกวิชา งานที่ค้าง/ต้องส่งวันนี้ และ “ถ้าส่งวันนี้ได้สูงสุดเท่าไร” · ไม่ต้องสมัคร · ครูพิมพ์ใบรหัส + QR แจกได้ (หน้านักเรียน → รหัสดูคะแนน) · สร้างรหัสใหม่ได้ถ้ารหัสหลุด |

### การหักคะแนนส่งช้า

ตั้งค่าเริ่มต้นได้ในหน้าตั้งค่า และกำหนดเฉพาะงานได้ตอนสร้างงาน

- หักเป็น **%** หรือ **คะแนน** ต่อ **วัน** หรือ **สัปดาห์** ที่ช้า
- ผ่อนผัน N วันแรก · คะแนนต่ำสุดที่ยังได้ (เช่น ไม่ต่ำกว่า 50%) · นับเฉพาะวันจันทร์–ศุกร์ · ปัดเศษ (.5 / จำนวนเต็ม)
- ค่าเริ่มต้น: หัก 10% ต่อวันทำการ ได้อย่างน้อย 50% → งานเต็ม 10 ส่งช้า 3 วัน ได้ 7

ระบบเก็บ “คะแนนที่ทำได้” กับ “วันที่ส่ง” ไว้ แล้วคำนวณคะแนนสุทธิทุกครั้งที่แสดงผล
ถ้าเปลี่ยนนโยบายหรือกำหนดส่งภายหลัง คะแนนสุทธิจะคำนวณใหม่ให้ถูกต้องทันที

## ติดตั้งและ Deploy

### 1) สร้างฐานข้อมูล Supabase

1. สมัคร/เข้าสู่ระบบ <https://supabase.com> → **New project**
   - **Region: Southeast Asia (Singapore)** `ap-southeast-1`
2. เมนู **SQL Editor** → New query → รันไฟล์ใน `supabase/migrations/` **ตามลำดับ** (คัดลอกทั้งไฟล์มาวาง → **Run**)
   1. [`20261103000000_init.sql`](supabase/migrations/20261103000000_init.sql) — ตารางหลัก + RLS
   2. [`20261104000000_student_portal.sql`](supabase/migrations/20261104000000_student_portal.sql) — รหัสดูคะแนนของนักเรียน
3. เมนู **Project Settings → API** (หรือ Data API / API Keys) จดค่า
   - `Project URL`
   - `Publishable key` (`sb_publishable_...`) — หรือ `anon` key แบบเดิมก็ใช้ได้
4. (แนะนำ) **Authentication → Sign In / Providers → Email**
   - ถ้าใช้คนเดียวหรือในโรงเรียน ปิด **Confirm email** ได้ จะสมัครแล้วใช้ได้ทันที

### 2) Deploy บน Vercel

โปรเจกต์ `kengscore` ในทีม Sarawut สร้างไว้แล้ว (เปิดสาธารณะเฉพาะ production, preview ต้องล็อกอิน) เลือกวิธีใดวิธีหนึ่ง:

**แบบ A — เชื่อม GitHub กับ Vercel (แนะนำ deploy อัตโนมัติทุกครั้งที่ push)**
ต้องใช้บัญชี GitHub ที่อนุญาตแอปภายนอกได้ → <https://vercel.com/new> → Import repository นี้
(ถ้า GitHub แจ้งว่าบัญชีถูก flag ต้องขอปลดก่อนที่ <https://support.github.com>)

**แบบ B — deploy จากคอมพิวเตอร์ด้วย Vercel CLI (ไม่ต้องใช้ GitHub)**
ติดตั้ง Node.js LTS จาก <https://nodejs.org> → ดาวน์โหลดโค้ด (GitHub → Code → Download ZIP) แล้วแตกไฟล์ →
เปิด Terminal ในโฟลเดอร์นั้น แล้วรัน (ครั้งแรกจะให้ล็อกอิน Vercel และเลือกโปรเจกต์ `kengscore`)

```bash
npx vercel@64.7.0 --prod
```

**แบบ C — GitHub Actions** ไฟล์ [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) deploy ให้ทุกครั้งที่ push
เมื่อมี secret `VERCEL_TOKEN` (สร้างที่ <https://vercel.com/account/tokens>) — ใช้ได้เมื่อบัญชี GitHub เปิดใช้ Actions ได้

ค่า Supabase ใส่ที่ Vercel → Project kengscore → **Settings → Environment Variables** แล้ว deploy ใหม่

> ยังไม่ได้ตั้งค่า Supabase ก็เปิดเว็บได้ — จะมีปุ่ม **โหมดสาธิต** ให้ลองใช้พร้อมข้อมูลตัวอย่าง (เก็บในเบราว์เซอร์เท่านั้น)

### 3) รันในเครื่อง (สำหรับพัฒนา)

```bash
npm install
```

```bash
cp .env.example .env.local   # แล้วใส่ค่า Supabase
```

```bash

```

## ขั้นตอนใช้งานครั้งแรก

1. สมัครด้วยอีเมล → ใส่ชื่อผู้สอนและภาคเรียน/ปีการศึกษาที่ทำงาน
2. **นักเรียน → นำเข้า / วางจาก Excel**: ใน Excel เลือกคอลัมน์ ชั้น ห้อง เลขที่ เลขประจำตัว คำนำหน้า ชื่อ นามสกุล → คัดลอก → วาง (มีปุ่มดาวน์โหลดแม่แบบ)
3. **รายวิชาและห้อง → เพิ่มรายวิชา** แล้วติ๊กห้องที่สอน
4. **กรอกคะแนน** → เลือกห้อง → **สร้างงาน** (ประเภท ชื่องาน คะแนนเต็ม กำหนดส่ง) → กรอกคะแนน
5. เปิดภาคเรียนใหม่: **ตั้งค่า → เพิ่มภาคเรียน** แล้ว **นักเรียน → คัดลอกจากภาคอื่น**

## นักเรียนดูคะแนนของตัวเอง

1. ครูเปิด **นักเรียน → รหัสดูคะแนน** → **พิมพ์ใบรหัส + QR** (A4 ได้ 10 ใบ) หรือ **คัดลอกรายชื่อ + รหัส** ไปวางใน LINE
2. นักเรียนสแกน QR หรือเข้า `https://<เว็บของคุณ>/s` แล้วกรอกรหัส
3. ครูปิดชั่วคราวได้ที่ **ตั้งค่า → นักเรียนดูคะแนนของตัวเอง**

ความปลอดภัย: รหัสสุ่ม 8 ตัว (≈ 8.5 × 10¹¹ แบบ เดาไม่ได้) · นักเรียนอ่านตารางในฐานข้อมูลตรง ๆ ไม่ได้
ต้องผ่านฟังก์ชัน `student_report` ซึ่งคืนเฉพาะคะแนนของเจ้าของรหัส ไม่รวมโน้ตของครูหรือข้อมูลเพื่อน ·
รหัสผูกกับนักเรียนในภาคเรียนนั้น (ขึ้นภาคใหม่ได้รหัสใหม่)

## โครงสร้างข้อมูล

```
terms (ภาคเรียน/ปีการศึกษา)
 ├─ classrooms (ชั้น/ห้อง) ── students (เลขที่ เลขประจำตัว คำนำหน้า ชื่อ นามสกุล)
 └─ subjects (รายวิชา) ── subject_classrooms (ห้องที่สอน)
     └─ assignments (ประเภทงาน ชื่องาน คะแนนเต็ม กำหนดส่ง นโยบายส่งช้า)
         ├─ assignment_due_dates (กำหนดส่งเฉพาะห้อง)
         └─ submissions (นักเรียน · คะแนนที่ทำได้ · วันที่ส่ง · ยกเว้นหัก)
settings (ต่อผู้สอน: ภาคเรียนที่ทำงาน ชื่อ ประเภทงาน นโยบายส่งช้า เปิดให้นักเรียนดูคะแนน)
students.access_code → student_report(code) ให้นักเรียนดูคะแนนตัวเอง
```

ทุกตารางมี `owner_id` และ RLS policy `owner_id = auth.uid()` · ลบภาคเรียน/ห้อง/วิชา ข้อมูลที่เกี่ยวข้องถูกลบตาม (cascade)
